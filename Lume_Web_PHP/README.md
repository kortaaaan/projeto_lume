# Lume Web — PHP + MySQL

Versão inicial do Lume usando PHP, MySQL, HTML5 semântico e CSS3.

## Instalação

1. Coloque a pasta `Lume_Web_PHP` em `C:\xampp\htdocs\`.
2. Ligue Apache e MySQL no XAMPP.
3. Abra `http://localhost/phpmyadmin`.
4. Importe `database/lume.sql`.
5. Acesse `http://localhost/Lume_Web_PHP/`.

## Banco

Por padrão:
- Host: 127.0.0.1
- Porta: 3306
- Usuário: root
- Senha: vazia
- Banco: lume

Se seu MySQL usar outra senha, altere `config.php`.
